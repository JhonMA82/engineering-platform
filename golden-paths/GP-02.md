# GP-02 — Admin Application

Aplicaciones operativas privadas: solicitudes, expedientes, CRM, backoffice y workflows.

- Default: `tanstack-admin` + `hono-api`.
- Alternativas: Next para producto público/privado integrado; SpeedPy cuando Python y una UI simple reducen capas.
- Datos: `postgresql-managed`; Turso/libSQL solo como piloto permitido.
- Features iniciales: auth, RBAC, audit y observability.
- Gates: lint, types, test, integración, migración, build y seguridad.
- Evitar: multitenancy, mobile y jobs hasta que una necesidad los active.

Ejemplo: solicitudes de una escuela single-tenant con adjuntos y aprobación.
