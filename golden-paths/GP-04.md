# GP-04 — Mobile Application

Aplicaciones que necesitan cámara, GPS, push, tienda o experiencia nativa.

- Default: `ignite` + `hono-api`.
- Datos: PostgreSQL; `turso-sync` experimental solo con diseño de conflictos.
- Features iniciales: auth y observability.
- Gates: lint, types, test, integración, build y seguridad.
- Evitar: app nativa si una PWA cubre el trabajo; sync de escritura sin autoridad definida.

Ejemplo: inspectores capturan evidencia y ubicación en campo.
