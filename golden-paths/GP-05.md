# GP-05 — Desktop Application

Herramientas instalables con filesystem, procesamiento local u operación offline.

- Default: `tauri-ui`.
- Datos: `sqlite-local`; `turso-sync` solo como piloto explícito.
- Features iniciales: observability.
- Gates: lint, types, test, build, seguridad e instalador.
- Evitar: permisos amplios, shell genérico o backend remoto sin una necesidad compartida.

Ejemplo: procesador local de PDFs para personal administrativo.
