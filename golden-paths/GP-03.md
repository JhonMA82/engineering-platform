# GP-03 — Python Data Application

Aplicaciones dominadas por Excel, documentos, OCR, reportes y procesos de datos.

- Default: `speedpy`.
- Alternativas: `speedpy-lite`, Full Stack FastAPI o servicio Python pequeño.
- Datos: PostgreSQL; SQLite para operación local compatible.
- Features iniciales: auth, audit y observability.
- Gates: lint, types, test, integración, migración y seguridad.
- Evitar: SPA separada, realtime o microservicios sin ventaja necesaria.

Ejemplo: importar 50 archivos Excel, explicar errores y generar reportes reproducibles.
