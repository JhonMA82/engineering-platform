# Skills

`skills/registry.json` registra instrucciones reales en `.opencode/skills/`. La Recipe limita cuáles necesita el proyecto y `eng plan` reduce el contexto según el tipo de cambio.

El skill más importante para evolución del catálogo es `boilerplate-curator`: normaliza una URL, detecta duplicados y aliases, inspecciona evidencia, compara cobertura y decide alta, referencia, refresh, reemplazo o rechazo.

No se registra una skill sin archivo ejecutable ni se carga una mega-skill con todo el catálogo.
