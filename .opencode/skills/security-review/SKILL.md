# Security Review

Identifica entradas no confiables, secretos, datos personales, acciones privilegiadas y dependencias nuevas. Revisa validación, autorización, rate limits, logging seguro, supply chain y mínimo privilegio. Para IA incluye prompt injection, tool allowlist, confirmación humana, fuga de datos y presupuesto. Produce hallazgos verificables con severidad y mitigación.
