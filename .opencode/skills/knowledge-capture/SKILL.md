# Knowledge Capture

Después de un incidente o tercer uso repetido, decide entre knowledge entry, canonical example, feature pack, skill o mejora del starter. Registra contexto, síntoma, causa, solución, verificación y límites. No generalices desde un caso aislado. Si cambia una decisión de plataforma, añade ADR y actualiza catálogo, Recipe, validator y changelog juntos.
