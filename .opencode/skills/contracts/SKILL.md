# Contracts

Define primero request, response, errores y compatibilidad. Mantén una fuente de verdad y genera clientes cuando el stack lo soporte. Para cambios incompatibles prepara versión o migración de consumidor. Prueba contrato, autorización, idempotencia y errores; no dupliques modelos de dominio en cada cliente.
