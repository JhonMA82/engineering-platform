# React Starter Kit: merge-seed

Esta Recipe complementa, no sustituye, el skill nativo del upstream. Antes de actualizar, el agente debe leer `.agents/skills/merge-seed/SKILL.md` dentro del proyecto generado.

## Política

Upstream es dueño del mecanismo; el proyecto es dueño de identidad y alcance. Los conflictos se resuelven por intención, las migraciones aplicadas no se reescriben y el pin solo cambia después de que instalación congelada, typecheck, lint, tests, build y gates del proyecto terminen correctamente.
