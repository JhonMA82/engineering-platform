# Upgrade Recipes

Cada starter se actualiza según su estrategia declarada: curated diff, regeneración, Copier, release interno o merge-seed. Una Recipe incluye detección, precondiciones, pasos, checks, evidencia y rollback.

React Starter Kit tiene una implementación inicial en [`react-starter-kit/merge-seed`](react-starter-kit/merge-seed/README.md). Los proyectos no reciben upgrades automáticos sin rama revisable ni migración planificada.
