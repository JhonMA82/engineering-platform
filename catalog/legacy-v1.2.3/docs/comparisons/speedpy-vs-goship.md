# SpeedPy vs. GoShip

## SpeedPy gana cuando

- Hay Excel, CSV, pandas, Polars o DuckDB.
- Se generan documentos y reportes.
- Django Admin facilita soporte.
- El sistema es CRUD/workflow institucional.
- OCR, ML o IA Python son centrales.

## GoShip gana potencialmente cuando

- Muchas conexiones SSE.
- Notificaciones en tiempo real.
- Receptores intensivos de webhooks.
- Footprint operativo bajo medido.
- Concurrencia y binario Go simplifican el despliegue.

## Prueba obligatoria para GoShip

El piloto debe medir:

- CPU/RAM.
- conexiones concurrentes.
- latencia.
- complejidad de implementación.
- horas de saneamiento.
- cobertura de pruebas.
- facilidad de mantenimiento con OpenCode.
- costo de operar Redis/PostgreSQL y notificaciones.

Si la ventaja no es clara, usar la base ya dominada por la consultoría.
