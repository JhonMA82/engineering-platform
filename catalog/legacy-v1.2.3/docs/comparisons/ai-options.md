# Opciones de IA: código, plataforma e infraestructura

## AI Assistant Starter

Elegir para producto personalizado, UX propia, permisos, herramientas y auditoría.

## Dify

Elegir cuando el cliente necesita configurar workflows y agentes con menos código. No sustituye una aplicación con UX y dominio propios.

## RAGFlow

Evaluar cuando el problema principal es recuperación documental y calidad sobre documentos.

## Self-hosted AI Starter Kit

Usar para POC local e infraestructura inicial, no como producto listo.

## Docling

Usar como componente de parsing documental dentro de SpeedPy, Python Service o un pipeline de IA.

## Regla

La plataforma no debe contener la única copia de prompts, workflows o reglas críticas. Exportar, versionar y probar.
