# Deprecación

## Causas

- Abandono.
- Cambio de licencia.
- Vulnerabilidad no corregida.
- Alternativa claramente superior.
- Actualización inviable.
- Costo operativo excesivo.
- Piloto fallido.

## Proceso

1. Marcar `deprecated`.
2. Documentar razón.
3. Congelar último commit aprobado.
4. Definir alternativa.
5. Crear guía de migración.
6. No eliminar historial.

## GoShip

Su estado actual no es deprecated: es `specialized_candidate`. Todavía no ha pasado el gate de piloto.
