# Licencias

## Antes de adoptar

- Identificar licencia del repositorio.
- Revisar dependencias y assets.
- Verificar obligaciones de distribución.
- Revisar licencias de fuentes, iconos y plantillas.
- Confirmar modelo de licencia de plataformas autoalojadas.

## Este repositorio

No incluye una licencia por decisión deliberada. Antes de publicarlo se debe elegir:

- privado;
- MIT para scripts y estructura;
- Creative Commons para documentación;
- combinación con archivos separados.

No asumir que la licencia de un boilerplate se transfiere a este catálogo.
