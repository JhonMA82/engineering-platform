# Proceso de revisión

## Cadencia

- Antes de cada proyecto.
- Trimestral para seleccionados y recomendados.
- Semestral para candidatos especializados.
- Inmediata ante CVE, cambio de licencia o abandono.

## Evidencia

- README y docs oficiales.
- Releases.
- Commits.
- Issues relevantes.
- Licencia.
- Build reproducido.
- Tests.
- Piloto.
- ADR.

## Resultado

- Mantener.
- Promover.
- Degradar.
- Deprecar.
- Retirar.

## No usar métricas superficiales

Estrellas y forks pueden aportar contexto, pero no sustituyen arquitectura, licencia, pruebas, actividad ni capacidad interna de mantenimiento.
