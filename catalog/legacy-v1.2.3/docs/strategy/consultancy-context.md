# Contexto de la consultoría

## Servicios principales

- Desarrollo de soluciones a medida.
- Automatización e integración.
- IA aplicada a productividad.
- Optimización de procesos.
- Digitalización y modernización operativa.

## Clientes objetivo

- Gobiernos.
- Escuelas.
- Sindicatos.
- Pymes.

## Características recurrentes

Estos clientes suelen trabajar con:

- Excel, CSV y bases heredadas.
- Oficios, reglamentos, contratos y expedientes.
- Procesos manuales con múltiples aprobaciones.
- Usuarios no técnicos.
- Presupuesto operativo limitado.
- Necesidad de autoalojamiento o control de datos.
- Conectividad variable.
- Requerimientos de auditoría y trazabilidad.
- Integraciones con sistemas existentes.

## Consecuencia para el catálogo

El catálogo no debe optimizarse alrededor de “hacer SaaS con Next.js”. Debe cubrir:

1. Presencia pública.
2. Operación administrativa.
3. Datos y documentos.
4. API e integraciones.
5. Móvil y escritorio.
6. IA gobernada.
7. Automatización.
8. Despliegue privado.
9. Tiempo real especializado.

## Principio central

Elegir la arquitectura mínima que conserve una ruta razonable de crecimiento. Una herramienta de datos no necesita React por defecto; una API multicanal no debe quedar encerrada en un monolito si varios clientes la consumirán.
