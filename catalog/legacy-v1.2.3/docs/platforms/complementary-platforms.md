# Plataformas complementarias

No se cuentan como boilerplates de aplicación, pero pueden reducir trabajo.

| Plataforma | Papel | Regla |
|---|---|---|
| n8n | Automatización e integración | Versionar workflows y no ocultar reglas críticas |
| Activepieces | Alternativa de automatización extensible | Evaluar cuando TypeScript y conectores propios sean ventaja |
| Directus | API/admin sobre datos | Útil para catálogos y backends rápidos |
| Appsmith | Herramientas internas | Prototipos y apps operativas simples |
| Metabase | BI e indicadores | No reconstruir reportes exploratorios desde cero |
| Dify | Workflows y apps de IA | Plataforma configurable, no sustituto universal |
| RAGFlow | RAG documental | Evaluar para precisión documental |
| Docling | Parsing de documentos | Integrar como librería o servicio |
| MinIO | Almacenamiento S3 compatible | Opción autoalojada |
| PostgreSQL | Base relacional | Default institucional salvo razón distinta |

## Criterio build vs. buy/open source

Construir el dominio y la experiencia diferencial. Integrar capacidades maduras para BI, storage, automatización y parsing cuando su operación sea aceptable.
