# IA documental: Dify, RAGFlow y Docling

## Dify

Encaja cuando se necesitan:

- Workflows configurables.
- Agentes.
- RAG.
- Herramientas.
- Observabilidad de aplicaciones de IA.
- Participación de perfiles menos técnicos.

No sustituye una aplicación a medida cuando UX, permisos o dominio son centrales.

## RAGFlow

Evaluar cuando:

- La recuperación documental es el núcleo.
- Importan parsing, chunks y referencias.
- Se requiere una plataforma especializada para experimentar con RAG.

No asumir que una plataforma elimina la necesidad de evaluar exactitud, cobertura, citas y seguridad.

## Docling

Es un componente de procesamiento documental. Integrarlo en:

- SpeedPy.
- Python Service Starter.
- Pipelines RAG.
- Ingesta de PDF y documentos.

Su papel es preparar documentos; no resuelve por sí solo permisos, búsqueda, respuestas o UX.

## Estrategia

- Dify: aplicación/workflow configurable.
- RAGFlow: especialización documental.
- Docling: parsing e ingestión.
- AI Assistant Starter: producto personalizado gobernado.

## Evaluación obligatoria

- Calidad sobre documentos reales.
- Tablas, imágenes y layouts.
- Citas.
- Idioma español.
- Costos.
- Privacidad.
- Prompt injection.
- Actualización de fuentes.
