# Catálogo y memoria de decisiones

La fuente operativa es `platform/boilerplates.json`. Este directorio conserva las fichas extensas y la versión completa `1.2.3` del repositorio anterior para no perder comparaciones, riesgos ni decisiones históricas.

- `profiles/`: fichas nuevas o actualizadas desde la migración.
- `legacy-v1.2.3/`: snapshot documental del antiguo `boilerplates-catalog`.

Una entrada del catálogo no equivale a un starter listo. Consulta `decision_status` para saber si conviene y `delivery_status` para saber si existe un artefacto reproducible y probado.
