# Contributing

Un cambio de plataforma debe ser reusable, probado y sin detalles de cliente.

Checklist:
- ¿es project change o platform change?
- ¿requiere ADR?
- ¿requiere eval?
- ¿rompe proyectos existentes?
- ¿requiere upgrade recipe?
- ¿incluye ejemplo entendible por un junior?
- ¿actualiza CHANGELOG?
