# Flujo: incidente

Ejemplo: un capturista pudo aprobar una solicitud.
1. Revocar/mitigar.
2. Reproducir.
3. Crear test que demuestra el privilege escalation.
4. Corregir policy backend.
5. Ejecutar matriz completa de permisos.
6. Registrar knowledge entry.
7. Si el patrón está en el starter, crear fix + upgrade recipe para proyectos afectados.
