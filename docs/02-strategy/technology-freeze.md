# Technology Freeze

El freeze significa **defaults estables**, no prohibición de aprender.

Una tecnología nueva entra al proceso solo si cubre una categoría no resuelta o mejora materialmente una limitación medida. El agente primero ejecuta `eng boilerplate evaluate`, compara contra las entradas vigentes y registra evidencia con `boilerplate-curator`.

## Evidencia mínima

- brecha concreta y proyectos que la necesitan;
- licencia compatible;
- señales de mantenimiento y estrategia de actualización;
- instalación, tests y build reproducibles;
- seguridad y costo operacional;
- comparación con el default y costo de migración.

Una alta comienza `catalog-only`. La selección como default y la liberación productiva son decisiones posteriores e independientes.

**Válido:** una necesidad GIS, offline real o runtime contractual que ningún camino cubre.

**Inválido:** otro framework React con la misma cobertura y una API ligeramente distinta.
