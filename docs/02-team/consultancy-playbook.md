# Consultancy Playbook

## Antes de propuesta
Intake y clasificación: new build, automation, integration, modernization, data/docs, AI productivity. No prometer stack antes del brief.

## Kickoff
Golden Path aprobado, repo, ambientes, owners, manifest y CI verde.

## Delivery
Specs pequeñas, ramas cortas, gates, revisión de drift y demos desde entorno desplegado.

## Handoff
Runbooks, backups, ownership de credenciales, ADRs, project map, límites y update policy.

## Después
Capturar incidentes y aprendizajes reusable; no contaminar plataforma con peculiaridades de cliente.
