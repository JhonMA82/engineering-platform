# Modelo operativo del equipo

## Roles lógicos
- Platform Owner: Golden Paths, releases, ADRs transversales.
- Project Lead: brief, Golden Path, manifest y desviaciones.
- Developer + AI Agent: specs pequeñas, canonical examples, gates.
- Reviewer: comportamiento, arquitectura, seguridad, migraciones.
- Operations Owner: CI/CD, secretos, backups, observabilidad, runbooks.

## Daily workflow
Tarea verificable → contexto mínimo → plan → implementación → gates → revisión de diff → PR → CI → knowledge decision.

La IA puede escribir mucho código; la responsabilidad sigue siendo humana.
