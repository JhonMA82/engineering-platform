# Flujo: entrega y mantenimiento

Antes de entregar:
1. release estable;
2. manifest actualizado;
3. runbooks probados;
4. backup/restore probado según criticidad;
5. ownership de cuentas/proveedores transferido;
6. known limitations documentadas;
7. update policy definida;
8. support window y responsabilidad acordadas.

En mantenimiento, cada cambio sigue el mismo manifest + Golden Path + quality gates. No volver al modo de prompts improvisados por tratarse de soporte.
