# Principios

1. Simplicidad suficiente.
2. Golden Paths sobre acumulación de frameworks.
3. Features opcionales.
4. Monolito modular primero.
5. Contrato API explícito.
6. Agentes generan; herramientas deterministas verifican.
7. Conocimiento acumulativo.
8. Upstream controlado.
9. Proyectos independientes de merges del starter.
10. Sistema de diseño propio y consistente.
