# Governance

## Fuente de verdad
Los JSON de `platform/` gobiernan catálogo, Golden Paths, feature packs y compatibilidad.

## Autoridad
- Platform Owner aprueba cambios transversales.
- Project Lead puede desviarse mediante ADR sin modificar la plataforma.
- Security-sensitive changes requieren reviewer adicional.

## Cadencia
- revisar stack trimestralmente, no semanalmente;
- revisar vulnerabilidades de inmediato;
- revisar starters antes de iniciar un proyecto nuevo;
- evaluar platform metrics mensualmente durante adopción.

## Deprecación
Una capacidad se depreca antes de eliminarse. Documentar alternativa, proyectos afectados y migration path.
