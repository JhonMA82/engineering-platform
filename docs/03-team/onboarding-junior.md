# Onboarding para juniors

## Semana 1
- Día 1: Start Here + glosario.
- Día 2: seguir ejemplo de escuela sin modificar arquitectura.
- Día 3: implementar un campo nuevo.
- Día 4: provocar y corregir un test de permisos.
- Día 5: abrir PR y explicar Golden Path + gates.

## Semana 2
- agregar una feature pack pequeña en sandbox;
- crear un ADR sencillo;
- ejecutar un eval del harness;
- documentar un problema/solución.

## Señal de autonomía
Puede explicar por qué NO necesita una tecnología, no solo cómo usarla.
