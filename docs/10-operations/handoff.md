# Handoff — ejemplo

Al entregar el sistema escolar, otro ingeniero debe recibir:
- repo y tag;
- Architecture Brief + manifest;
- ADRs;
- ambientes;
- mapa de secretos (sin valores);
- deploy/rollback;
- backup/restore;
- monitoreo;
- proveedores;
- limitaciones conocidas.

Objetivo: operar sin reconstruir mentalmente el proyecto.
