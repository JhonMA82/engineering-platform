# Project Manifest

`.engineering/project.json` es la identidad técnica del proyecto.

Debe registrar:
- versión de Engineering Platform;
- Golden Path;
- starters y versiones/commits;
- feature packs;
- apps activas;
- decisiones/ADRs relevantes;
- runtime/deployment cuando sea material.

El harness debe leerlo antes de proponer arquitectura. Los upgrades lo modifican únicamente después de verificar que la migración fue exitosa.
